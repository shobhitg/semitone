Semitone — test harness

A known signal and a fake “next track”, so you can tell a broken extension from a difficult website. Serve this folder over http and open it in the profile where the extension is loaded.

1 · Does the audio graph work

A C major arpeggio — C, E, G, C. Press play, then click the extension and press + twice. You should hear the same shape a whole tone higher, with no clicks and no dropouts.

track: tone-a.wav · url: /

2 · Does it reset between tracks

This is the feature. Set a key with the extension, then press each button. The on-screen readout should snap to 0 and flash “Reset — new track”. The toolbar badge should clear too.

All three simulate a YouTube soft navigation. None of them reload the page — if the key survives any of them, the reset watcher has a gap.

3 · Does the host-app bridge work

No extension id needed — this page just posts a window message, the way any local web app would. Setting −2 should show that key in the on-screen readout.
